## Release Boundary

v0.1.0 covers (as documented in `v0.1.0-acceptance.md`):

- In-process governance runtime (package version 0.1.0)
- Policy engine with 12 operators
- Decision resolver
- SQLite-backed timelines (6 tables, 3 migrations)
- Path validation
- Evaluation and regression services
- Read-only replay/audit
- Framework-neutral adapter contract (`LocalCallableAdapter`)
- Read-only HTTP server (GET only)
- Full CLI (run/replay/audit/eval/policy validate)
- `examples/hello.py` runnable demo

v0.1.0 explicitly excludes:

- Automatic evidence-only review mode
- Multi-agent orchestration
- Automatic remediation
- Runtime governance beyond the documented v0.1.0 scope
- Phase 5 platformization (dashboard, HTTP write API, Postgres, MCP, multi-tenant server)

## Phase 1 Non-Goals

Phase 1 (Clarify Evidence Integration) is scoped and documented but not implemented.
Per `docs/strategy/phase1-readiness.md` and `docs/contracts/phase1-evidence-only-contract.md`:

- No HTTP write API or auth system
- No browser runtime coupling
- No Clarify-defined core schema mutation
- No dashboard, UI platform, or observability frontend
- No Phase 5 platformization features
- No automatic evidence-only review mode
- No bypass of governance decisions
- No change to runtime acceptance rules

Evidence ingestion, timeline export, and evidence-based evaluation are deferred to
Phase 1 implementation packs.
