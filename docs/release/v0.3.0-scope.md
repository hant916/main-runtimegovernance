# Ailuros v0.3.0 MVP Scope

**Pack:** 0085.v03-readiness-closeout
**Date:** 2026-06-05
**Status:** scope-frozen

## MVP Scope

v0.3 MVP delivers exactly three capabilities on top of the accepted v0.2 evidence pipeline:

| Capability | Description | Evidence |
|---|---|---|
| Audit package exporter | Export audit packages from stored evidence timeline, including governance decisions | `src/ailuros/audit/package_export.py` (extends v0.2 audit section) |
| Refund governance demo | A single deterministic demo exercising evidence-to-audit-package flow with a refund governance scenario | Demo fixture + tests |
| v0.3 acceptance gate | Release smoke check, release tests, and scope boundary guard analogous to v0.2 acceptance | `scripts/check_release_v030.py`, `tests/test_release_v030.py` |

## Non-goals (v0.3)

The following are explicitly **not in scope** for v0.3:

- Server write API (`do_POST`/`do_PUT`/`do_PATCH`/`do_DELETE`)
- UI dashboard or observability frontend
- Agent orchestration or multi-agent runtime
- Browser governance or realtime browser-event integration
- Clarify integration inside `src/ailuros/` core
- radarCreation integration inside `src/ailuros/` core
- MCP Gateway integration
- Broad adapter ecosystem
- Multi-tenant server or platformization
- Any new runtime mode or backend service

## Dependency

v0.3 depends on v0.2 evidence pipeline being accepted (`docs/release/v0.2.0-acceptance.md` status: accepted).

## Validation

Before v0.3 can be released, the following must pass:

- `scripts/check_release_v030.py` (all checks)
- `tests/test_release_v030.py` (all tests)
- Full test suite (`python -m pytest tests -q`)
- Core boundary guard (no domain-specific terms in `src/ailuros/`)
