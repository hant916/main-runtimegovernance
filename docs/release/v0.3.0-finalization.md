# Ailuros v0.3.0 Release Finalization

Date: 2026-06-05
Status: finalized

This document records the final v0.3.0 release boundary and validation evidence.

## Release Boundary

v0.3.0 contains exactly the accepted MVP scope:

- Audit package exporter for stored governance runs.
- Low-level structured audit package export.
- Deterministic refund governance demo.
- v0.3 release smoke check and acceptance tests.

## Explicit Non-Goals

v0.3.0 does not introduce:

- UI dashboard or observability frontend.
- Server write API.
- Production Clarify, radarCreation, or browser governance integration.
- MCP Gateway integration.
- Broad adapter ecosystem or plugin system.
- Agent orchestration or multi-agent runtime.
- Multi-tenant platformization.

## Validation Boundary

The final release validation commands are:

```bash
python scripts/check_release_v020.py
python scripts/check_release_v030.py
python -m ruff check .
python -m mypy src
python -m pytest tests -q
```
