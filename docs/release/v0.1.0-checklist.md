# v0.1.0 Release Checklist

Run each step manually. Do not proceed past a failing item without fixing it first.

## Pre-tag checks

- [ ] **Clean git state** — `git status` shows no unstaged or untracked files (except intentional ignores).
- [ ] **Tests pass** — `python -m pytest tests -q` exits 0.
- [ ] **Version** — `pyproject.toml` contains `version = "0.1.0"`.
- [ ] **Changelog** — `CHANGELOG.md` has a `## v0.1.0 (2026-06-04)` entry describing all v0.1 changes.
- [ ] **Hello demo** — `python examples/hello.py` prints five governance artifacts without error.
- [ ] **ADR presence** — `docs/decisions/ADR-0001-ailuros-as-governance-runtime.md` exists.
- [ ] **Roadmap presence** — `docs/strategy/roadmap.md` exists with Phase 5 marked as explicitly deferred.
- [ ] **Phase 5 scope deferral** — No Phase 5 capability (dashboard, HTTP write API, Postgres, MCP, framework adapter implementation, multi-tenant server) is implemented or advertised as v0.1 deliverable.

## Tag commands (manual, documented only)

```bash
git tag -a v0.1.0 -m "v0.1.0 — Ailuros Governance Runtime initial release"
git push origin v0.1.0
```

After tagging, create a GitHub release from the tag with changelog content.

## Scope boundary reminder

v0.1.0 covers: in-process runtime, policy-gated tool calls, SQLite-backed timelines, path validation, CLI (run/replay/audit/eval/policy validate), framework-neutral adapter contract skeleton, and the refund demo. Phase 5 platformization (server, REST API, dashboard, adapter implementations) remains deferred.
