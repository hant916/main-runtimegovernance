# v1.5 — Post-Run Governance Reporting

**Status:** Accepted

**Date:** 2026-06-06

## Scope

v1.5 adds **deterministic report rendering** over the v1.5 post-run governance
audit. It introduces a generic Markdown report renderer and a source-neutral CLI
command for auditing a canonical evidence package on disk in either JSON or
Markdown form.

v1.5 is **post-run governance validation before HTTP ingestion and runtime
decision APIs.** It inspects a completed run's evidence package after the fact
and reports a single pass/warn/fail decision. It does not see, intercept, or
control live execution, and it introduces no allow/review/block runtime surface.

## What's included

- A generic, source-neutral Markdown renderer in `ailuros.core.report`
  (`render_audit_markdown`).
- An evidence-package wrapper `audit_result_to_markdown` exposed from
  `ailuros.adapters.evidence_package`.
- A CLI command `ailuros evidence-audit <package-path> --format json|md`, with an
  optional `--out` for writing the report to a file.
- A golden Markdown report and tests asserting deterministic output.

## What's explicitly out of scope

Unchanged from the v1.5 contract: no HTML dashboard, PDF export, web server, HTTP
endpoint, database report history, or charts. The audit and validation rules are
unchanged; v1.5 only renders fields that earlier packs already produce. No new
`BLOCKED` or `HUMAN_REVIEW` path is introduced.
