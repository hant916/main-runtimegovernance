## Non-goals (v0.3)

- This release does **not** introduce a UI dashboard or observability frontend.
- This release does **not** introduce a server write API (do_POST, do_PUT, do_PATCH, do_DELETE).
- This release does **not** introduce production integrations (Clarify, radarCreation, browser governance).
- This release does **not** introduce MCP Gateway integration.
- This release does **not** introduce a broad adapter ecosystem or plugin system.
- This release does **not** introduce agent orchestration or multi-agent runtime.
