# Ailuros v0.2.0 Release Acceptance

## Release status

Status: acceptance-defined

## Capability claimed

v0.2.0 delivers **evidence-only capability**: structured `EvidenceRecord` ingestion,
timeline storage, JSON/JSONL export, evidence-based evaluation, and regression
testing. Evidence enters the runtime from reference-application fixtures; no
runtime control flows back to external applications.

## Required checks

- EvidenceRecord model is defined and exported from `ailuros.evidence`.
- Evidence ingestion (`ingest_evidence`) stores records into the runtime timeline.
- Evidence export (`export_evidence`, `export_evidence_json`, `export_evidence_jsonl`)
  produces correct output.
- Reference-app fixtures (Clarify, EverRun, RadarCreation) validate against the
  evidence contract.
- Evidence-based evaluation and regression tests pass.
- Phase 1 evidence-only contract (`docs/contracts/phase1-evidence-only-contract.md`)
  is present and scoped as evidence-only.
- Phase 1 readiness document (`docs/strategy/phase1-readiness.md`) is present.
- Release smoke script (`scripts/check_release_v020.py`) passes.
- Full test suite passes.
- No `src/ailuros/` source file is modified by this acceptance gate.

## Non-goals

- This release does not introduce an HTTP write API or server write methods
  (`do_POST`, `do_PUT`, `do_PATCH`, `do_DELETE`).
- This release does not introduce a reference-application core dependency;
  Clarify vocabulary does not enter `src/ailuros/`.
- This release does not introduce automatic evidence-only review mode.
- This release does not introduce multi-agent orchestration or automatic remediation.
- This release does not introduce dashboard, UI platform, or observability frontend.
- This release does not introduce Phase 5 platformization features (multi-tenant
  server, REST API, Postgres, MCP, adapter ecosystem).
- This release does not claim server write API support.
- This release does not claim real Clarify integration inside core.

## Explicit deferrals (Phase 1 boundary)

| Feature | Rationale |
|---|---|
| HTTP write API | Ailuros remains in-process; v0.2 uses local ingestion |
| Auth / session management | Out of scope for local runtime kernel |
| Dashboard or UI | Not a platformization goal |
| Realtime browser blocking | No runtime control from browser into Ailuros |
| Clarify-defined core schema | Clarify-specific types never appear in `src/ailuros/` |
| Full Clarify browser adapter | Adapter contract exists; no browser adapter is implemented |
| Phase 5 platformization | Multi-tenant server, REST API, Postgres, MCP |
